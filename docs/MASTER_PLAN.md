| Phase | 状態 | 成果 |
|---|---|---|
| 0 現状監査 | 完了 | `PHASE0_AUDIT_REPORT.md` |
| 1 実体inventory・研究台帳設計 | 未着手 | DB/model/data inventory、データ辞書、追記専用schema案 |
| 2 予測・実験記録 | 未着手 | 予測/結果/model/experiment保存、手動採用フロー |
| 3 時系列検証 | 未着手 | as-of特徴量、walk-forward、基準モデル |
| 4 確率・EV評価 | 未着手 | Log Loss/Brier/Calibration/ROI比較 |
| 5 安全な改善運用 | 未着手 | 承認済み候補の比較・採用 |

禁止事項: AIによる自動本番採用、リーケージの許容、既存DB・データ・機能の破壊、短期ROIだけによる改善判断。
